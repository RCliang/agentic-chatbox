# Frontend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build React SPA with dark theme, chat interface, and admin pages.

**Architecture:** React 18 + TypeScript SPA. Zustand for state, React Router v6 for routing, Tailwind CSS for dark theme styling, custom SSE hook for streaming. Pages: Login, Chat (main), Admin/Knowledge, Admin/Skills.

**Tech Stack:** React 18, TypeScript, Vite, Tailwind CSS v3, Zustand, React Router v6, react-markdown.

**Backend API base URL:** `http://localhost:8000`

### Task 2: Login Page + Auth

**Files:**
- Create: `frontend/src/api/client.ts` (axios instance with JWT interceptor)
- Create: `frontend/src/stores/authStore.ts` (Zustand: user, token, login, logout)
- Create: `frontend/src/pages/LoginPage.tsx`
- Create: `frontend/src/App.tsx` (router setup)
- Create: `frontend/src/main.tsx` (entry point)

- [ ] **Step 1: Create frontend/src/api/client.ts**

Axios instance with base URL `http://localhost:8000`, request interceptor to add Bearer token, response interceptor to handle 401 (redirect to /login).

- [ ] **Step 2: Create frontend/src/stores/authStore.ts**

```typescript
interface AuthState {
  user: null | { id: string; username: string; display_name: string; is_dept_admin: boolean; department_id: string | null; position: string | null };
  token: string | null;
  login: (username: string, password: string) => Promise<void>;
  logout: () => void;
  fetchMe: () => Promise<void>;
}
```

On login: POST /api/auth/login, store token + user in localStorage.
On logout: clear token + user.
On app start: check localStorage for token, call fetchMe to validate.

- [ ] **Step 3: Create frontend/src/pages/LoginPage.tsx**

Dark theme login page: centered card, username + password inputs, submit button. On success redirect to /. Show error message on failure.

- [ ] **Step 4: Create frontend/src/App.tsx**

React Router setup:
- `/login` → LoginPage
- `/` → ChatPage (protected)
- `/admin/knowledge` → KnowledgePage (protected)
- `/admin/skills` → SkillsPage (protected)
- PrivateRoute wrapper that redirects to /login if no token

- [ ] **Step 5: Verify**

Run: `cd frontend && npm run dev`, visit /login, should see login form.


**Files:**

- [ ] **Step 1: Create frontend/src/hooks/useSSE.ts**

Custom hook that takes a URL and POST body, creates EventSource-like using fetch + ReadableStream, parses SSE events, returns { stream, events, isStreaming }.

```typescript
// Key: use fetch with ReadableStream to POST SSE
// Parse "event: xxx\ndata: {...}\n\n" format
// Return real-time event objects
```

- [ ] **Step 2: Create frontend/src/stores/chatStore.ts**

State:
- conversations: list
- currentConversationId: string | null
- messages: Message[]
- isStreaming: boolean
- mode: "normal" | "agentic"

Actions:
- fetchConversations()
- createConversation(title, mode)
- selectConversation(id)
- sendMessage(content)
- setMode(mode)

sendMessage: POST /api/chat/send, use useSSE hook, accumulate text events into messages, handle tool_call/tool_result/thinking events for agentic mode.

- [ ] **Step 3: Create Sidebar component**

Dark sidebar (w-64), list of conversations with title and mode badge. "New Chat" button at top. Click to select conversation. Highlight active.

- [ ] **Step 4: Create ChatArea component**

Main content area. Top bar with mode toggle (Normal/Agentic tabs), title. Message list. Bottom input area with KB selector and text input.

- [ ] **Step 5: Create MessageBubble component**

Renders a message. User messages right-aligned with dark bg. Assistant messages left-aligned. Support markdown rendering via react-markdown.

- [ ] **Step 6: Create AgentStep component**

For agentic mode: collapsible sections showing thinking, tool_call, tool_result events with distinct styling (red for thinking, green for tool_call, purple for tool_result).

- [ ] **Step 7: Create ModeToggle component**

Two tabs: Normal (blue) / Agentic (red). Switching creates a new conversation in the selected mode.

- [ ] **Step 8: Create KBSelector component**

Row above input showing selected knowledge base tags with × to remove, and "+" button to add (opens a simple dropdown/modal of available KBs fetched from GET /api/knowledge/bases).

- [ ] **Step 9: Create ChatPage**

Layout: Sidebar | ChatArea. On mount, fetch conversations. Auto-create first conversation if none exist.

Run: `cd frontend && npm run dev`. Should see chat layout with sidebar and input.
